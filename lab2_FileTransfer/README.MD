# MyProtocolTransferData

Программа для передачи файлов между клиентом и сервером по TCP с отображением скорости передачи.  

---

## Описание

- Сервер принимает соединения от нескольких клиентов одновременно.  
- Клиент передает серверу имя файла в кодировке UTF-8, размер файла и его содержимое.
- Клиент передает файл серверу.  
- Сервер сохраняет файлы в поддиректории `uploads` текущей директории.  
- Сурвер гарантирует, что не выходит за поддерикторию `uploads`.
- Во время передачи сервер выводит:  
  - Мгновенную скорость передачи для каждого зашружаемого файла.  
  - Среднюю скорость передачи за весь сеанс передачи файла.  
- Поддерживается параллельная работа с несколькими клиентами с использованием потоков.  
- Проверяется целостность файла (размер полученного файла сравнивается с переданным).  

---

## Структура проекта

- `Server/` — серверная часть.  
- `Client/` — клиентская часть.  
- `ProtocolLibrary/` — Библиотека для реализации протокола передачи.  

---

## Протокол передачи

- Передается имя файла (UTF-8), размер файла и содержимое файла.  
- Используется TCP.  
- Структура сегмета передаваемых данных:
  - Размер сегмента.
  - Номер сегмента
  - Тип сегмента:
    - Информация о файле.
    - Данные из файла.
    - Ошибка передачи.
    - Отмена передачи.
    - Отключение клиента/сервера.
    - Успешный прием предыдущего сегмента.
  - Размер полезных данных.
  - Порядковый номер полезных данных.
  - Полезные данные (байты файла).

## Как запустить

### Сборка

Для сборки используйте .NET 9 (или совместимую версию):

```bash
dotnet build
````

### Запуск сервера

```bash
dotnet run --project Server -- <порт>
```

* `<порт>` — порт, на котором сервер будет принимать соединения.

### Запуск клиента

```bash
dotnet run --project Client -- [опции]
```
### Опции

* `-a <ip>` — IP-адрес сервера.

* `-p <port>` — порт, на котором сервер принимает соедиения.

* `-d` <hostname> - доменное имя сервера.

---

## Особенности

* Поддержка нескольких клиентов через потоки (ThreadPool).
* Отдельные строки консоли для отображения скорости загрузки каждого файла.
* Защита от записи за пределы папки `uploads`.
* Проверка целостности переданных файлов.

---

## Примечания

* Размер файла не более 1 ТБ.
* Длина имени файла до 4096 байт в UTF-8.
* Сервер автоматически добавляет суффикс `(n)` к файлу, если файл с таким именем уже существует.
