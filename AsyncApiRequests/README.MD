# AsyncApiRequests

Приложение для асинхронного взаимодействия с несколькими публичными API, предоставляющими информацию о локациях, погоде и интересных местах.  

---

## Описание

Программа позволяет пользователю ввести название места, получить координаты, узнать текущую погоду, прогноз и список интересных локаций с описаниями.  
Все сетевые запросы выполняются **асинхронно** с использованием `HttpClient` и `async/await`.  

---

## Логика работы

1. Пользователь вводит название места.  
2. Программа обращается к API для получения координат (через **GraphHopper API**).  
3. По координатам запрашивается погода и прогноз (через **Open-Meteo API**).  
4. Затем выполняется запрос к **OpenTripMap API** для получения интересных мест рядом.  
5. Для каждого найденного места запрашивается подробное описание (также через **OpenTripMap API**).  
6. Все результаты собираются в общий объект и выводятся пользователю.  

---

## Асинхронность

- Все независимые запросы выполняются **параллельно**.  
- Зависимые запросы (например, получение погоды после координат) образуют **цепочку задач**.  
- Используются только **асинхронные методы**, без блокировок `Wait()` или `.Result`.  
- Итоговая функция возвращает `Task` (аналог `CompletableFuture` из Java).  

---

## Используемые API

| API | Назначение                           |
|-----|--------------------------------------|
| **GraphHopper API** | Поиск координат по названию места    |
| **Open-Meteo API** | Получение текущей и почасовой погоды |
| **OpenTripMap API** | Поиск интересных мест и их описаний  |

## Как запустить

### Сборка

Для сборки используйте .NET 9:

```bash
dotnet build
````

### Запуск

```bash
dotnet run
```

После запуска программа запросит ввод названия локации:

```
Enter name of location which you want to search ("exit" for exit):
```

Введите, например:

```
Москва
```

Программа выполнит все запросы и выведет информацию о погоде и интересных местах.

## Особенности

* Полностью асинхронная архитектура без блокировок.
* Поддержка русских символов в консоли Windows.
* Использование нескольких публичных API с объединением данных.

## Примечания

* Необходимо интернет-соединение.
* При использовании некоторых API может потребоваться регистрация и получение API-ключа.
