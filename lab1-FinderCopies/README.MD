# FinderCopies

Программа для обнаружения копий самой себя в локальной сети с помощью **multicast UDP** сообщений.  
Каждый экземпляр приложения отправляет в multicast-группу "heartbeat" пакеты и одновременно слушает ту же группу.  
Таким образом, программа может отслеживать, какие копии сейчас "живы", и выводить список их IP-адресов.

---

## 🔹 Возможности

- Поддержка **IPv4** и **IPv6** (определяется автоматически по адресу группы).
- Автоматическое обнаружение новых копий приложения в сети.
- Удаление "мертвых" записей после таймаута.
- Уведомления о смене IP-адреса копии.
- Гибкая настройка через параметры командной строки.

---

## 🔹 Параметры запуска

```bash
dotnet FinderCopies.dll -- [опции]
````

### Опции

* `-a <ip>` — IP-адрес multicast-группы.
  Примеры:

  * IPv4: `239.255.0.1`
  * IPv6: `ff02::1`

* `-p <port>` — порт multicast-группы.

* `-h` или `--help` — вывод справки.

---

## 🔹 Примеры запуска

### Запуск с IPv4 группой

```bash
dotnet run -- -a 239.255.0.1 -p 25565
```

### Запуск с IPv6 группой

```bash
dotnet run -- -a ff02::1 -p 25565
```

### Запуск из собранной DLL

```bash
dotnet bin/Debug/net8.0/FinderCopies.dll -a 239.255.0.1 -p 25565
```
